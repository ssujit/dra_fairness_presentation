# FAIRness: Presentation Preparation, Collaboration & Sharing

A 60-minute training presentation on applying the FAIR principles to
scientific presentations. The material covers preparation, collaboration,
sharing, version control, reproducibility, and publication of presentation
resources.

## Audience

Researchers, doctoral candidates, research support staff, and research data
managers.

## Learning objectives

After the session, participants should be able to:

- Apply FAIR principles to scientific presentations.
- Prepare and organize reproducible presentation materials.
- Use Marp and Markdown for human-readable, interoperable slides.
- Collaborate on presentation sources with Git.
- Export and share presentations using appropriate metadata and licensing.

## Repository contents

- `2026_slides_sikder_fairness_presentation.md` — Marp slide source.
- `2026_slides_sikder_fairness_presentation.pdf` — exported PDF presentation.
- `assets/` — images and figures used by the slides.
- `draw/` — editable source files for selected diagrams.
- `CITATION.cff` — machine-readable citation information.
- `references.bibtex` and `metadata.text` — reference and metadata resources.

## Viewing and editing

Open the Markdown file in Visual Studio Code with the
[Marp for VS Code](https://marketplace.visualstudio.com/items?itemName=marp-team.marp-vscode)
extension. Use the Marp preview to edit the slides and export them as PDF,
HTML, or other supported formats.

Keep the slide source, assets, figure source files, references, and metadata
in one version-controlled repository.
